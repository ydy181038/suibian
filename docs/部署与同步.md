# 部署与 GitHub 同步

## 1. 本机运行

环境要求：Windows 10/11 + Python 3.10 以上，不需要 Node.js、MySQL 或 SQL Server。

```powershell
cd ev-parking
python server.py
```

或直接双击 `启动VoltPark.bat`，脚本会自动检测服务、启动并打开 http://127.0.0.1:8777。

数据库位于 `data/voltpark.db`，首次启动自动建表并写入演示数据；删除该文件即可恢复出厂数据。

## 2. 本机 Git 配置

| 项目 | 值 |
| --- | --- |
| Git 版本 | 2.56.1（Git for Windows） |
| 安装位置 | `%LOCALAPPDATA%\Programs\Git` |
| PATH | 已加入用户 PATH：`...\Git\cmd`、`...\Git\ucrt64\bin` |
| 全局配置 | `%USERPROFILE%\.gitconfig`（默认分支 main、autocrlf、长路径） |
| 提交身份 | `ydy181038 <355293011+ydy181038@users.noreply.github.com>` |
| 远程仓库 | `git@github.com:ydy181038/suibian.git` |

> 说明：当前 Windows 用户目录包含中文，Git 自带的 OpenSSL/SSH 组件在部分场景下无法正确读取该路径。因此 SSH 私钥放在纯 ASCII 目录 `C:\ProgramData\VoltPark\ssh`，并通过 `GIT_SSH` 包装脚本调用系统自带的 `C:\Windows\System32\OpenSSH\ssh.exe`。

## 3. 仓库结构

```text
ev-parking/
├── server.py              # HTTP 服务、REST API、认证与会话
├── db.py                  # SQLite schema、演示数据与自动维护
├── security.py            # 密码哈希、会话令牌、输入校验
├── static/                # 原生 HTML / CSS / JS 单页应用
├── data/                  # 本地数据库目录（.db 已被 .gitignore 排除）
├── docs/                  # 数据库设计、建表 SQL、界面截图
├── 启动VoltPark.bat
├── README.md
└── CHANGELOG.md
```

## 4. 日常同步流程

```powershell
cd ev-parking
git status
git add -A
git commit -m "说明本次改动"
git push
```

首次拉取或换机后：

```powershell
git clone git@github.com:ydy181038/suibian.git
```
